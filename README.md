# Ruta KM0 · sitio de soporte y privacidad

Páginas públicas de la app iOS **Ruta KM0** (Transportes Ruta KM0, Camilo Ponce Enríquez, Ecuador),
publicadas con GitHub Pages para App Store Connect.

- `index.html`: soporte (qué es la app, para quién, contacto por WhatsApp, preguntas frecuentes).
- `privacidad.html`: política de privacidad en español (texto de referencia).
- `privacy.html`: la misma política en inglés.
- `estilos.css`: estilos a mano con la línea gráfica (naranja #D9631E, grafito #1F2A37).

HTML y CSS sin frameworks ni dependencias externas. Para cambiar la política, edite las dos
versiones a la vez y actualice la fecha de vigencia.
